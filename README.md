The official AdamGrounds open source repository, built with [Godot Engine](https://godotengine.org/).

## Getting Started

1. Download and install [Godot Engine](https://godotengine.org/download).
2. Clone this repository:
   ```
   git clone https://github.com/love-buggedd/adamgrounds.git
   ```
3. Open Godot, click **Import**, and select the `project.godot` file.

**Note:** `assets/scripts` and `scenes/` has been removed from the public Repository. Metadata for those folders may be attributed in the future.
